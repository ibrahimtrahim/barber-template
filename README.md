<h1>Hair Studio Website</h1>

<p>This is the repository for the Hair Studio website, created using HTML, CSS, and JavaScript. The website is designed to showcase the services, stylists, and booking options for a modern barber studio.</p>

<h2 id="description">Description</h2>
<p>The Hair Studio website provides a modern and clean interface for clients to learn about the studio, view stylist profiles, and book appointments online. It is fully responsive and optimized for both desktop and mobile devices.</p>

<h2 id="features">Features</h2>
<ul>
    <li>Responsive design</li>
    <li>Service listings</li>
    <li>Stylist profiles</li>
    <li>Online booking form</li>
    <li>Contact information</li>
    <li>Interactive elements using JavaScript</li>
</ul>

<h2 id="technologies-used">Technologies Used</h2>
<ul>
    <li>HTML5</li>
    <li>CSS3</li>
    <li>JavaScript</li>
</ul>

<h2 id="installation">Installation</h2>
<p>To run this project locally, follow these steps:</p>
<ol>
    <li>Clone the repository: <code>git clone https://github.com/your-username/hair-studio.git</code></li>
    <li>Navigate to the project directory: <code>cd hair-studio</code></li>
    <li>Open <code>index.html</code> in your preferred web browser.</li>
</ol>

<h2 id="usage">Usage</h2>
<p>Once the project is opened in the browser, you can navigate through the different sections of the website, view stylist profiles, and use the online booking form to schedule an appointment.</p>
